## What is SAGO?

**SAGO** is a high-performance autonomous AI software engineering agent operating directly in your terminal. Designed from the ground up to solve complex software engineering challenges, SAGO bridges deep static code intelligence with multi-agent orchestration.

Whether navigating a massive 10,000+ file polyglot monorepo, refactoring core abstractions across 50 files concurrently, or exploring an unfamiliar architecture, SAGO executes with surgical precision, automated syntax verification, and zero hallucination safeguards.

## Core Philosophy

### 1. Prototype First & Zero-Friction Out-of-the-Box
SAGO requires **zero initial credit card or paid API keys**. Fresh installations default to the free tier (`openrouter/free`), allowing you to launch `sago tui` immediately and start inspecting code. When you're ready, switch effortlessly to Claude 3.7 Sonnet, OpenAI GPT-4o, Google Gemini 2.5 Pro, or local Ollama models via `F6` or `/model`.

### 2. Surgical Context Over Brute Force
Feeding 100 raw files into an LLM context creates severe attention diffusion (*"Lost in the Middle"* syndrome) and hallucinations. SAGO employs a **4-Phase Scale Architecture**:
1. **Git-Aware Incremental Indexing:** Detects repository state in <20ms using `git ls-files` fast paths.
2. **Universal Skeletonization:** Omits implementation bodies (`{ ... }`) to outline 10,000 files in under 3,000 tokens.
3. **Graph Neighborhood Traversal:** Explores 2 hops of callers and callees around the target symbol.
4. **Context Poisoning Safeguards:** Caps massive changesets to recent modifications plus aggregate directory clusters.

### 3. Project-Scoped Isolated Learning
SAGO learns from past command corrections, syntax errors, and architectural patterns. Rather than polluting global memory across unrelated projects, SAGO isolates project conventions into `<project_root>/.sago/learning.json` while maintaining cross-cutting tool fixes globally in `~/.sago/learning.json`.
