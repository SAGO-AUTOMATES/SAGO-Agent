## Overview

Developer Mode provides deep, transparent visibility into SAGO's internal execution loop. It tracks microsecond latencies, prompt payloads, function-calling arguments, agent delegations, and thinking blocks.

<Note>
**v0.1.14+ Default:** Developer Mode is **enabled by default** during the beta release. Fresh installs immediately provide live traces without needing manual configuration.
</Note>

## Configuration

Control Developer Mode via multiple channels:

### 1. Slash Commands in TUI
```bash
# Toggle Developer Mode
/dev toggle

# Force ON or OFF
/dev on
/dev off

# Open the live telemetry modal
/dev inspector
```

### 2. User Configuration (`~/.sago/settings.json`)
```json
{
  "dev_mode": true
}
```

### 3. Environment Variable
```bash
# Force enable
export SAGO_DEV_MODE=1

# Force disable
export SAGO_DEV_MODE=0
```

## Tracing Architecture (`DevTracer`)

The telemetry engine (`sago/tui/dev_tracer.py`):
1. **Zero Model Context Pollution:** Telemetry events and debug stats are dispatched to UI callbacks and never appended to LLM conversation payloads.
2. **Microsecond Precision:** Measures exact wall-clock latencies across network calls, tool executions, and file I/O.
3. **Session Artifacts:** Traces are written to `.sago/traces/` in structured JSON for retrospective analysis.
