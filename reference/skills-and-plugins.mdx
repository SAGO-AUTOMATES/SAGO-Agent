## 1. Custom Skills (`SKILL.md`)

Skills define domain-specific, repeatable operating procedures that agents activate when solving specialized tasks.

### Discovery Locations
SAGO automatically scans:
- **Project Skills**: `.sago/skills/<skill_name>/SKILL.md` or `skills/<skill_name>/SKILL.md`
- **Global Skills**: `~/.sago/skills/<skill_name>/SKILL.md`

### Anatomy of a `SKILL.md`

A skill file consists of YAML frontmatter metadata followed by Markdown instructions:

```markdown
---
name: database-migration
description: Safely plans, tests, and executes database schema migrations with automated rollback checkpoints.
tools:
  - execute_shell
  - read_file
  - write_file
  - checkpoint_ops
steps:
  - Create atomic workspace snapshot with checkpoint_ops
  - Verify existing schema and generate reversible migration script
  - Run test suite against temporary database
  - Apply migration and verify table consistency
tags:
  - database
  - migration
  - devops
---

# Database Migration Procedure

When performing database migrations:
1. Always create a pre-migration snapshot before touching any schema files.
2. Inspect models and verify foreign key constraints.
3. Generate reversible UP/DOWN migration scripts.
4. Execute test suites to ensure zero regression before committing.
```

### Inspecting & Hot-Reloading Skills

In the SAGO TUI:
- `/skills`: List all active project and global skills.
- `/skill reload`: Re-scan skill directories and reload changes from disk instantly.
- <kbd>Ctrl+R</kbd>: Global hot-reload of all skills, plugins, and settings.

## 2. Python Plugins (`BasePlugin`)

Plugins hook directly into the agent runtime lifecycle, allowing you to intercept messages, inspect tool inputs, modify results, or register custom services.

### Drop-in Locations
- **Project Plugins**: `.sago/plugins/<plugin_name>.py`
- **Global Plugins**: `~/.sago/plugins/<plugin_name>.py`

### Plugin Example

```python
"""Custom security audit plugin."""

from sago.plugins.base import BasePlugin

class SecurityAuditPlugin(BasePlugin):
    name = "security_audit_hook"
    version = "1.0.0"

    async def on_user_message(self, message: str) -> str:
        """Called before the user message reaches the orchestrator."""
        # Sanitize sensitive access tokens or credentials
        return message

    async def on_tool_before_execute(self, tool_name: str, args: dict) -> None:
        """Called immediately before a tool is executed."""
        if tool_name == "execute_shell":
            print(f"Executing command: {args.get('command')}")

    async def on_tool_after_execute(self, tool_name: str, result: str) -> str:
        """Called after tool completes; can sanitize or augment output."""
        return result
```
